# 💸 FinBot — Telegram-бот для личных финансов

Превращает «мелкий шрифт» банков в понятные цифры.

| Модуль | Что делает |
|---|---|
| **Вклады** | итог, **эффективная ставка**, график роста, сравнение типов капитализации |
| **Сравнение вкладов** | несколько предложений → рейтинг по реальной доходности |
| **Кредиты** | переплата, график платежей (CSV + диаграмма), **проценты за первые 3 месяца**, доля процентов, уплаченная за первый год |
| **Подводные камни** | «снимешь через 3 месяца — ставка упадёт до 0.01% — потеряешь 52 344» |
| **Валюты** | конвертер на open.er-api.com (без ключа, ~160 валют) |
| **Подписки** | напоминания о списании + «сколько это стоит в год» |

Понимает и команды, и обычный текст: `Вклад 500к 10% на год, капитализация каждый месяц, снять через 3 месяца`.

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env          # впишите токен от @BotFather
export $(grep -v '^#' .env | sed 's/ *#.*//' | xargs)
python -m finbot
pytest                         # 13 тестов на математику и парсинг
```

## Структура
```
finbot/calc.py      — вся финансовая математика (чистые функции, покрыты тестами)
finbot/parsing.py   — разбор русского текста: «500к», «1.5 млн», «на полгода», «ежедневно»
finbot/render.py    — готовые сообщения; без зависимости от Telegram
finbot/charts.py    — графики matplotlib
finbot/rates.py     — курсы валют с кэшем на 1 час
finbot/storage.py   — подписки в SQLite
finbot/bot.py       — handlers python-telegram-bot, ежедневный job в 09:00
```

## Формулы
- Вклад: `S = P·(1 + r/n)^(n·t)`, целые периоды — сложный процент, «хвост» — простой.
- Эффективная ставка: `EAR = (1 + r/n)^n − 1`.
- Аннуитет: `A = P·i / (1 − (1+i)^−N)`, `i = r/12`. Дифференцированный: долг `P/N` + проценты на остаток.

## Идеи для развития
- Комиссии и страховка кредита → полная стоимость (ПСК/APR)
- Досрочное погашение: «сколько сэкономлю, если вношу +5 000 в месяц»
- Вклады с пополнением и ступенчатыми ставками
- Inline-кнопки вместо текстовых команд, вебхук вместо polling, деплой на Fly.io/Railway

⚠️ Расчёты ориентировочные: банки округляют и считают дни по-разному (365/366, 30/360). Не финансовая рекомендация.
